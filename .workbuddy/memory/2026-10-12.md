- 上述 `.gitignore` 无法解决：wrangler 4.149.0 无视 `.git/` 忽略规则。确认当前项目本质是 Workers（跑 `npx wrangler deploy`），不是纯 Pages，受 25MB 单文件限制。
- 重构仓库以瘦身：原图移入 `originals/`（仅本地存档，不进 git/不部署）；灯箱改用 `medium/`（1600px，约 8.8MB）；网格用 `thumbs/`（约 3.4MB）。build_site.py 已同步更新。部署体积降至约 12MB，规避 25MB 限制。
- 结论：建议用户删除当前 Cloudflare 项目，重建为**真正的 Pages 项目**（Framework=None，Build command 留空，Output=`.`），不再走 wrangler。
- 进一步发现该项目为 Workers + Assets 类型，Deploy / Preview command 是必填项，无法绕过 wrangler。于是改为标准 Wrangler 方案：
  - 新增 `wrangler.jsonc`，将 `assets.directory` 指向 `./public`。
  - 修改 `build_site.py`，所有页面与图片生成到 `public/`（含 index.html、style.css、script.js、images/avatar.png、medium/、thumbs/）。
  - 删除根目录下重复的 index.html/style.css/script.js/medium/thumbs，避免冗余。
  - 本地从 `public/` 起服务器验证：index/css/js/thumb 均 200；`public/` 总大小约 18MB，远低于 25MB 限制。
  - Cloudflare 设置：Build command 留空；Deploy command 填 `npx wrangler deploy`；Preview command 填 `npx wrangler preview`。
